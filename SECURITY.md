# Security Policy

## Reporting a vulnerability

Please do not report suspected security vulnerabilities in a public GitHub issue.

Contact the maintainer privately through the contact information associated with the GitHub account or repository. Include the affected component, reproduction steps, potential impact, and any mitigation you have identified.

Please avoid destructive testing, accessing data that is not yours, or disrupting systems while investigating a report.

## Current support policy

Christine is currently in an early alpha stage. Security fixes are applied to the actively maintained development line unless a future release policy explicitly states otherwise.

Because Christine can interact with local system resources and optional external services, reports involving credential handling, desktop automation boundaries, local model execution, persisted state, or network-facing integrations are especially important.
